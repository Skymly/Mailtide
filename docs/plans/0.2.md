# 0.2 Move a Message to another Mailbox

## 产品句

The Person can move a selected Message into another Mailbox on the same Account (not only Trash).

False on origin/main: `IImapClient.MoveAsync` exists, but Core and the shell only call it for Trash and restore.

## Non-goals

- Creating, renaming, or deleting Mailboxes
- Gmail labels, or Archive as a special All Mail Mailbox
- Bulk multi-select / move many Messages at once
- Entra, JMAP, macOS/iOS
- Android background sync, FCM, WorkManager
- Conversation threading in the UI
- Changing CredentialKind or adding a second Credential path
- Avalonia control-tree tests
- Git tag / GitHub Release packing

## Vertical slice

One implement ticket (hop D) crossing the layers that actually change:

1. Core: `MoveMessageAsync(accountId, messageId, destinationMailboxId)` — IMAP `MoveAsync` to the destination Mailbox path, then set the local Message's MailboxId. Same Account only. No-op if already there. Error if destination is missing or on another Account.
2. BrowseShell: move the selected Message; reload the current Mailbox or Unified Inbox list.
3. Shared UI: a Move action that lets the Person pick a Mailbox on the current Account (list/picker on BrowseShell; MailShellView wires it). Desktop and Android share it.
4. Tests: Core + Desktop BrowseShell. Host/UI tests stay on BrowseShell. Live IMAP stays skipped unless a secret is already in the environment.

Trash / restore stay as they are. Move-to-Trash is not replaced by this ticket.

## Scope

In:

- `MailtideApp` move verb (not a pass-through module)
- Local store MailboxId update after a successful IMAP move
- BrowseShell + MailShellView Move
- Desktop tests

Out:

- New public Core module that only forwards `MoveMessageAsync`
- Per-minor `ready-for-human` 回归票
- Settings / notification preferences

## Acceptance

- [ ] From Inbox (or any Mailbox), the Person can move the selected Message to another Mailbox on that Account; the Message leaves the current list and appears in the destination after reload.
- [ ] Unified Inbox: moving an Inbox Message to a non-Inbox Mailbox removes it from Unified Inbox.
- [ ] Destination on another Account, or a missing Mailbox, is an error (no silent no-op except same Mailbox).
- [ ] Offline: IMAP failure leaves the Message where it was (no optimistic local-only move).
- [ ] Core + BrowseShell tests green. `.\build.cmd Test` green on the implement PR.
