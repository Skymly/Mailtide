# 0.8 Browse Unified Inbox Messages grouped by reply thread

## 产品句

The Person can browse Unified Inbox Messages grouped by reply thread.

False on origin/main: Mailbox browse groups reply chains (0.7), but Unified Inbox is still a flat Message list.

## Vertical slice

One implement ticket (hop D) crossing the layers that actually change:

1. Core: group Unified Inbox Messages by the same reply-chain ritual as Mailbox threads. `MailtideApp` stays the host-facing seam.
2. BrowseShell: Unified Inbox lists groups (latest Message subject/from/date); select a group to list its Messages.
3. Shared UI: reuse the 0.7 group-then-Messages click path. Per-Mailbox grouping is unchanged.
4. Tests: Core + Desktop BrowseShell with seeded reply chains across Inbox-role Mailboxes. Live IMAP skipped unless a secret is already in the environment.

No new public Core module that only forwards the verb.

## Scope

In:

- `MailtideApp` Unified Inbox grouping at the existing list seam
- BrowseShell + MailShellView Unified Inbox list
- Desktop tests

Out:

- New public Conversation type or store table

- [ ] Per-Mailbox grouping from 0.7 is unchanged.
- [ ] Core + BrowseShell tests green. `.\build.cmd Test` green on the implement PR.
