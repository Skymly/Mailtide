# 0.21 Product-grade Fluent daily shell

## 产品句

The Person uses a compact Fluent 3-pane daily shell: Account/Mailbox tree, Thread list, and a reading pane that compose can replace. Chrome is Compose + Sync. Object actions live on context menus and Outlook-style Ctrl+ chords.

## Non-goals

- Phone / narrow-width folding
- Multi-select / bulk actions
- Nested Mailbox paths
- Unifying local Draft with the Drafts-role Mailbox
- New mail capabilities (snooze, scheduled send)
- Relitigating ADR-0001 / ADR-0002 / ADR-0003

## Vertical slice

1. Shared Avalonia shell: CommandBar (Compose + Sync), update banner under it, full-page empty state when there are zero Accounts, otherwise TreeView | Thread list | reading.
2. List rows are Threads (sender-first). Selecting a Thread stacks its Messages in the reading pane; attachments sit on a Thread strip.
3. Compose replaces the reading pane. Local Drafts switch inside compose. Empty untitled Drafts auto-discard. Outbox is a per-Account left-nav item; Sync flushes it.
4. Shortcuts follow new Outlook (Ctrl+N / F9 / Ctrl+R / Delete / …). Gmail single keys are gone.
